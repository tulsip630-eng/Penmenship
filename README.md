# Penmenship

A lightweight handwriting and cursive practice web app.

## Features
- Trace **letters** or **sentences** in print or cursive guide mode.
- Draw directly on the practice board with mouse, touch, or stylus.
- Track consistency with a motivational progress bar (5-goal target).
- Cycle through fun, encouraging handwriting quotes.

## Run locally
Because this is a static app, you can open `index.html` directly, or serve it with:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
